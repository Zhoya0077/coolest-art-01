# The Lighthouse That Swims the Stars

An old lighthouse stands on a rocky island, its amber beam sweeping across a deep indigo night sky full of stars, nebulae, and two moons. Below, a dark ocean mirrors the starlight. The island drifts through the sky like a ship, carrying its light across the cosmos.

The image was composed as a single square scene built around one strong silhouette: the lighthouse tower against the brightest part of the sky. Warm amber light contrasts with cool blue night tones, so the picture still reads clearly when viewed small.

## Running the entry

Run the program from the repository root with python3 main.py.

The program copies entry.png into the output directory given by MAKEFUN_OUTPUT_DIR, or /output by default. It uses only the Python standard library and needs no network access.
